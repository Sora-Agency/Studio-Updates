# Studio Updates

Repositorio público de manifiestos firmados para las actualizaciones de Sora Studio. El código de la aplicación permanece en el repositorio privado.

El release estable publica `stable.json`. Studio verifica su firma Ed25519 y la licencia antes de ofrecer una versión; para instalarla, comprueba que el tag privado apunte al commit exacto indicado en el manifiesto.
